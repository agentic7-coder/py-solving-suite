# py-solving-suite 🧮🔧

A comprehensive Python toolkit for mathematical operations, geometric rule solving, encoding/decoding, and more.

## Features

- **Basic Operations** – add, subtract, divide, square, cube
- **Roots & Powers** – square root, cubic root, power root
- **Geometry Solvers** – area, perimeter, volume, angle calculations
- **Encoder/Decoder** – custom encoding/decoding utilities
- **Extensible** – easily add new math rules and solvers

## Installation

```bash
pip install py-solving-suite
